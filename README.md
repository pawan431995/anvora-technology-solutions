# Anvora Technology Solutions

A responsive static company website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` - main website
- `css/style.css` - complete responsive styling
- `js/script.js` - mobile navigation, demo placeholders and email form

## Before publishing

Open `index.html` and replace:

1. `hello@anvoratechnology.com` with your real email.
2. `+91 99999 99999` with your real phone number.
3. The School ERP / Pathology Lab / Beauty Parlour demo links with your actual application URLs.
4. Company text, services and solution descriptions as required.
5. Add your real logo if you have one.

The "Suggest an App" form uses `mailto:` so it does not require a backend. The visitor's email application opens with the request pre-filled.

For production, a backend/contact API can be added later if you want submissions stored in a database.
